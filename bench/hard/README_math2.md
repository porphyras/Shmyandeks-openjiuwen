# Набор math2 (bench/sets/math2)

Дополнительный оценочный набор math из публичных бенчмарков, раскладка как у `bench/sets/hard`
(см. `README.md` рядом). 68 задач: 60 выполнимых и 8 невыполнимых, все ответы — целые положительные
числа (`check = exact_int`). Номера `math_0000`…`math_0067`, награда 1..5 детерминированно (SHA-256 от метки).
Инструкция = текст задачи + служебная фраза примеров организаторов слово в слово (`common.MATH_TAIL`,
сборщик сверяет её с `data/examples/task-dir`). task.json: ровно task_id/task_type/instruction/reward.
`keys.json[...]["meta"]` хранит источник и id исходной задачи.

## Команды

```bash
D=/path/to/math2_dl        # загрузки; каждый источник в своей новой пустой папке
mkdir $D/math500 $D/svamp $D/asdiv $D/gsm8k
curl -L -o $D/math500/test.jsonl https://huggingface.co/datasets/HuggingFaceH4/MATH-500/resolve/main/test.jsonl
curl -L -o $D/svamp/SVAMP.json https://raw.githubusercontent.com/arkilpatel/SVAMP/main/SVAMP.json
curl -L -o $D/gsm8k/test.jsonl https://raw.githubusercontent.com/openai/grade-school-math/master/grade_school_math/data/test.jsonl
for o in $(seq 0 100 2300); do
  curl -L -o $D/asdiv/$(printf rows_%04d.json $o) \
    "https://datasets-server.huggingface.co/rows?dataset=EleutherAI/asdiv&config=asdiv&split=validation&offset=$o&length=100"
done
python3 -I bench/hard/build_math2.py --dl $D [--show]   # ~1 с, пишет только bench/sets/math2
```

Загрузки читаются только как данные (JSON/JSONL), скрипт запускается с `python3 -I`, только стандартная
библиотека; код из загрузок не исполняется. Сборка детерминирована (две сборки подряд побайтно равны).
`--show` печатает все задачи с ответами. Копия MATH-500 в github.com/openai/prm800k лежит в git-LFS
(в raw — только указатель), поэтому берётся HF. ASDiv на HF только в parquet, поэтому строки берутся
JSON-страницами datasets-server (без авторизации). Сборщик читает `bench/sets/hard/keys.json`, чтобы
не взять задачи GSM8K, уже использованные в hard.

## Как получены задачи

**MATH.** Предметы Prealgebra, Algebra, Number Theory, Counting & Probability, уровни 3–5: 218 задач в
MATH-500. Последний `\boxed{}` решения совпадает с полем answer у всех; ответ — простое целое > 0 у 142.
Отбрасываются задачи с диаграммами (`[asy]`), индексами и системами счисления (`_`, «base»), переносами
`\\`, `\|`, а также любые LaTeX-команды вне короткого списка. Оставшаяся разметка переводится в простой текст:
`$...$` снимается, `\frac{a}{b}` → `a/b` (со скобками, если нужно: `(1/2)x^2`, `(1/sqrt(2))(x^2-3)`,
смешанное число `4 5/8`), `\sqrt{x}` → `sqrt(x)` (`4*sqrt(2)`), `\cdot`/`\times` → `*`, `^{10}` → `^10`,
`\le` → `<=`, `\neq` → `!=`, `\lceil..\rceil` → `ceil(..)`, `100^{\mathrm{th}}` → `100th`, `\$` → `$`, `1{,}000` → `1,000`;
в результате не должно остаться `\`, `{`, `}`. Прошли 113; берётся по квоте на предмет, сначала уровень 5,
внутри — порядок SHA-256 от id. Ответ MATH принимается как есть, но все 25 выбранных ответов дополнительно
пересчитаны отдельно (перебором или формулой) и совпали. Отброшена вручную prealgebra/2066 (округлять
каждую сумму или разность — 23 против 22).

**SVAMP.** Body и Question склеиваются (`$ 78` → `$78`, `do n't` → `don't`; тело без точки в конце —
придаточное «If …», к нему вопрос присоединяется через запятую со строчной буквы). Equation вычисляется точной
рациональной арифметикой (разбор AST через `common.safe_arith`), должен совпасть с Answer; каждое
промежуточное значение — целое ≥ 0; каждое число уравнения есть в тексте; без «висячих» апострофов
токенизации. Пул 969; порядок — больше различных чисел и операций, ответ не меньше 5, длиннее текст.
Из одной «истории» (первые два слова тела) берётся не больше одной задачи. Отброшены вручную (бессмысленные
пертурбации SVAMP): chal-506 («than on the previous 245 days»), chal-122 (спрашивает про raisin cakes),
chal-334 (в вазе 2 розы, выбросили 4), chal-985 («1091 weeks of harvest»), chal-35 (спрашивает число,
данное в условии, уравнение считает другое).

**ASDiv.** body + question; левая часть formula вычисляется так же и должна совпасть с правой частью и с
числом в поле answer (`9 (apples)`); промежуточные значения — целые ≥ 0; числа формулы есть в тексте
(цифрами или словами; разрешена неявная 1 — «started on the first floor»); ответы в центах — только если
в тексте есть «cent». Формулы с GCD/LCM/пропорциями/остатками не проходят разбор и отбрасываются.
Пул 1264, тот же порядок и правило одной истории. Отброшены вручную: 865 (неясно, все ли вышли на
конечной), 1986 («the mean of the people»), 1981 (второе «среднее списка»), 900 (та же история с
карандашами, что 628).

**GSM8K.** `build_math.parse_solution`: каждая аннотация `<<expr=res>>` пересчитана, итог — целое,
полученное одной из аннотаций. Исключены все 29 индексов из `bench/sets/hard/keys.json` (meta idx, включая
исходники GSM-Hard и невыполнимых) и `build_math.EXCLUDE`. Порядок — число шагов, затем длина. Отброшены
вручную: 409 (оплата «за два месяца» предполагает месяц = 4 недели), 161 («how many fish» — морские звёзды
и коньки считаются рыбами), 423 (спрашивает, насколько jogger дороже, а они на $8 дешевле), 696 («3 times
more points»).

## Невыполнимые (8, `vague_quantity`, expected = null)

Число, нужное решению, заменено на some/several/a few/a number of; вопрос не меняется.
- SVAMP/ASDiv (`vague_variant`): число встречается в тексте и в уравнении ровно по разу, не денежное и
  не в последнем предложении; пересчёт уравнения со значениями +1, +2, +7 обязан менять ответ.
  chal-534 (сколько крышек выбросил), chal-748 (сколько дней учился), ASDiv 709 (сколько морских звёзд),
  651 (сколько пакетов сока).
- GSM8K (`build_math.make_infeasible`, как в hard): воспроизведение цепочки калькулятора с другим значением
  обязано менять ответ; дополнительно отброшены варианты, где после пропуска идёт less/more/fewer/times/
  percent/as («costs several less»), и задача 100 («1/4 times more» неясно и с числом).
  Взяты 295 (сколько отжиманий в первый день), 155 (сколько булок в день).
- MATH (вручную, по решению): counting_and_probability/216 «several Republicans» — ответ
  C(R+6,5) − C(R,5) − C(6,5) зависит от R; counting_and_probability/765 «There are some people in my school» —
  включения-исключения дают total = 3P + 30, без размера школы P не находится.
Эти исходные задачи не входят в набор как выполнимые; все 8 прочитаны вручную.

## Проверки

- Раскладка: в task.json ровно 4 поля, id подряд, награда 1..5 и совпадает с keys.json, пустой workspace,
  у выполнимых `expected` — целое > 0 строкой, у невыполнимых null; инструкции уникальны, оканчиваются
  служебной фразой, в задачах MATH нет `\`, `{`, `}`.
- Индексы GSM8K не пересекаются с hard (`bench/sets/hard` и `h_math` используют одни и те же 29).
- Прогон `bench/grade.py` на эталонных answer.txt (папка прогона вне репозитория): 60/60, 173/173.
- Две сборки подряд побайтно равны.

## Замечания

- MATH-500 — самое популярное подмножество MATH, задачи могут быть знакомы моделям; сложность — в
  рассуждении (уровень 5), арифметика решается python.
- SVAMP/ASDiv — короткие задачи в 2–6 действий; сложнее их делают отвлекающие числа (SVAMP: «The school has
  66 classrooms») и несколько шагов, а не вычисления. Ответы ASDiv в своих единицах (628 — в центах, текст
  только в центах).
- Тексты GSM8K и SVAMP/ASDiv не правились, кроме перечисленной склейки; двойные пробелы GSM8K сохранены, как в hard.
- ASDiv лицензирован CC BY-NC 4.0: набор годится для внутренней оценки, не для коммерческого распространения.
